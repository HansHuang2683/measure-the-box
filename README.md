# 📦 FBA 装箱优化工具

FBA 装箱优化工具是一个面向亚马逊 FBA 卖家的装箱方案计算器。输入产品和箱子尺寸，自动计算最优装箱方案，满足 5 箱免配置费要求。

## 功能

- **SKU 管理** — 添加产品 SKU，支持硬包装/软包装分类和公差设置
- **箱子类型** — 支持标准箱规选择与自定义箱子（含壁厚设置）
- **混装组配置** — 手动或自动分配混装方案，验证同箱可行性
- **层架算法** — 基于高度优先的层架式 3D 装箱排布
- **空腔吸附算法** — 第二阶段利用空腔空间填充软包装产品，提升装载率
- **3D 可视化** — Three.js 实时渲染，支持：
  - 产品在箱内的精确排布位置
  - 沙盘交互模式：拖拽移动、X/Y/Z 轴 90° 旋转
  - 方向约束平移（沿指定轴方向拖拽）
  - 空腔可视化（半透明显示）
  - Ctrl+Z 撤销 / Ctrl+Y 重做
- **定制箱建议** — 根据剩余产品自动计算推荐外箱尺寸、箱数、摆放方向
- **xlsx 导入/导出** — 批量导入 SKU 数据，导出完整装箱报告

## 使用方法

1. 打开 `index.html`（纯前端，无后端依赖）
2. **第一步**：添加 SKU，填写名称、长宽高、数量和包装类型
3. **第二步**：选择或自定义箱子类型
4. **第三步**：配置混装组，或点击"自动分配方案"
5. **第四步**：查看结果，包括：
   - 装箱验证状态（已验证/估算/不可行）
   - 3D 布局预览
   - 定制箱建议（如有剩余产品）
   - 导出 xlsx 报告

## 技术栈

- 原生 JavaScript（ES6+）
- [Three.js](https://threejs.org/) r128 — 3D 渲染与交互
- [SheetJS](https://sheetjs.com/) — xlsx 导入导出
- 无构建工具，纯浏览器运行

## 项目结构

```
index.html              — 主页面
css/style.css           — 样式
js/
├── config.js           — 配置与工具函数
├── algorithm.js        — 单 SKU 装箱算法
├── algorithm-mixed.js  — 混装算法（层架 + 空腔）
├── algorithm-cavity.js — 空腔吸附算法
├── distribution.js     — 自动分配方案
├── customBox.js        — 定制箱建议算法
├── xlsxHandler.js      — xlsx 导入导出
├── renderer3d.js       — Three.js 3D 渲染与沙盘交互
└── ui.js               — UI 逻辑
```
